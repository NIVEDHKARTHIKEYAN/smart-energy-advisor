# AI-Based Smart Energy Advisor and Electricity Bill Optimizer

The AI-Based Smart Energy Advisor and Electricity Bill Optimizer is a web-based application designed to help households monitor estimated electricity consumption, calculate electricity bills, identify high-energy-consuming appliances, and discover opportunities to reduce electricity usage and costs.

The project is developed using HTML, CSS, and JavaScript for the frontend, Python Flask for backend development, SQLite for database management, and Chart.js for interactive data visualization. The application provides a modern, responsive dashboard that presents electricity consumption data in a clear and user-friendly format.

## Key Features

- **Interactive Dashboard:** Displays total estimated monthly electricity consumption, estimated electricity bill, number of registered appliances, highest-consuming appliance, and potential savings.
- **Appliance Management:** Supports household appliances such as fans, lights, refrigerators, air conditioners, televisions, washing machines, geysers, water pumps, laptops, computers, irons, microwave ovens, rice cookers, mixers, electric kettles, and custom appliances.
- **Electricity Consumption Calculator:** Calculates daily and monthly energy consumption for each appliance using its power rating, quantity, daily usage hours, and number of days.
- **Electricity Bill Calculator:** Estimates electricity costs based on energy consumption and configurable electricity tariffs, with scope for fixed charges and slab-based billing.
- **AI Energy Advisor:** Uses a rule-based recommendation system to identify energy-saving opportunities and suggest practical ways to reduce electricity consumption. The initial implementation does not claim to use machine learning.
- **Electricity Bill Optimizer:** Supports usage-reduction simulations to compare estimated electricity consumption and costs before and after optimization.
- **Charts and Reports:** Provides appliance-wise consumption charts, cost comparisons, consumption summaries, and downloadable reports as the relevant modules are implemented.
- **User Authentication:** Includes planned registration, login, and logout functionality with securely hashed passwords and user-specific data access.
- **Responsive Interface:** Offers a clean dashboard layout designed for desktop and mobile screens.
- **Database Integration:** Uses SQLite to store application data and support persistent appliance
